# Лабораторна робота №1 — Варіант 2 (система автоматизації роботи університету)

## Структура проєкту

```
lab1/
├── schema.sql                          # Завдання 1: реляційні таблиці (1-до-1, 1-до-багатьох, багато-до-багатьох)
├── Models/
│   ├── Group.cs                        # Завдання 2: модель "Група"
│   ├── Student.cs                      # модель "Студент"
│   ├── StudentCard.cs                  # модель "Студентський квиток"
│   ├── Course.cs                       # модель "Курс"
│   └── Enrollment.cs                   # таблиця-зв'язка (багато-до-багатьох)
├── Repository/
│   └── UniversityRepository.cs         # Завдання 3: репозиторій зберігання даних
├── Services/
│   └── UniversityInfoService.cs        # Завдання 4: сервіс виведення інформації
├── Program.cs                          # точка входу, заповнює тестові дані й демонструє роботу
└── UniversityApp.csproj                # файл проєкту .NET 8
```

## Які зв'язки де реалізовано

| Тип зв'язку        | Де в БД (schema.sql)                | Де в коді (C#)                                  |
|--------------------|--------------------------------------|--------------------------------------------------|
| Один-до-одного     | `Students` ↔ `StudentCards` (UNIQUE) | `Student.Card` / `StudentCard.StudentId`          |
| Один-до-багатьох   | `Groups` → `Students` (FK GroupId)   | `Group.Students` (List) / `Student.GroupId`       |
| Багато-до-багатьох | `Students` ↔ `Courses` через `Enrollments` | `Student.Enrollments`, `Course.Enrollments`, клас `Enrollment` |

## Як запустити

1. Встановіть .NET SDK 8.0 (https://dotnet.microsoft.com/download), якщо ще немає.
2. Розпакуйте архів в будь-яку папку.
3. У терміналі перейдіть у папку `lab1` і виконайте:
   ```
   dotnet run
   ```
4. Програма створить тестові групи, студентів, квитки, курси та запис на курси,
   після чого виведе всю інформацію в консоль (демонстрація роботи Завдання 4).

## Альтернатива: Visual Studio / Rider

Просто відкрийте `UniversityApp.csproj` у Visual Studio, Rider або VS Code
(з розширенням C#) і натисніть "Запустити" (F5).

## Примітка щодо schema.sql

Цей файл — окремий SQL-скрипт (не виконується разом з C#-кодом), який ілюструє,
як ці ж самі зв'язки виглядали б у реальній реляційній базі даних (Завдання 1).
Його можна виконати в SQL Server / SQLite / PostgreSQL (з невеликими правками
синтаксису IDENTITY під конкретну СУБД) для створення таблиць і перевірки на практиці.
